# Lab 5 – Marr-Hildreth Edge Detection

## Aim
Implement the Marr-Hildreth edge detection method using Gaussian smoothing, the Laplacian operator, and zero-crossing detection.

## Input Image
Place an image named **house.png** in this `Lab_5` folder. The program loads it in grayscale. The input image is required and is not generated by the script.

## Method
The program processes the input image with three Gaussian scale settings:

| Sigma | Gaussian kernel |
|---:|---:|
| 4 | 25 × 25 |
| 7 | 35 × 35 |
| 9 | 45 × 45 |

For each setting, it:
1. Smooths the grayscale image using a Gaussian filter.
2. Applies the Laplacian operator.
3. Computes the absolute Laplacian magnitude.
4. Detects zero crossings in horizontal, vertical, and both diagonal directions.
5. Produces edge maps with threshold (T=0) and (T=4\%\) of the maximum absolute Laplacian response.
6. Saves a 2 × 3 comparison figure.

## Files
- `Experiment_05.py` – complete Python implementation.
- `house.png` – input image; add this file to the folder before running.
- `output/` – created automatically and populated with the three result figures.

## Requirements
Install the required packages:

```bash
pip install opencv-python numpy matplotlib
```

## How to Run
From a terminal, change to the `Lab_5` directory and run:

```bash
python Experiment_05.py
```

The script uses Matplotlib's non-interactive `Agg` backend, so it saves figures without opening GUI windows.

## Expected Output
After a successful run, the `output` directory contains:
- `Marr_Hildreth_Sigma_4.png`
- `Marr_Hildreth_Sigma_7.png`
- `Marr_Hildreth_Sigma_9.png`

Each figure contains the original image, Gaussian-smoothed image, Laplacian magnitude, signed Laplacian, and two zero-crossing edge maps.

## Notes
- The program uses zero-crossing sign changes and marks both pixels adjacent to each crossing.
- The threshold for the second edge map is calculated separately for each sigma as 4% of that image's maximum absolute Laplacian response.
- Output figures are generated locally when the script is run. They cannot be precomputed without the actual `house.png` input image.
